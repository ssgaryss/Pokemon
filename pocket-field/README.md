# Pocket Field · 口袋原野

可游玩、可通关的原创 Game Boy 风格网页冒险。纯 HTML、CSS、JavaScript，无需安装依赖。

## 本地运行

在本目录执行 `npm run dev`，打开 http://127.0.0.1:4173 。

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动、选择 |
| Z / 空格 | A：确认、交谈 |
| X / Escape | B：返回 |
| Enter | START：菜单 |
| Shift | SELECT：图鉴 |

支持点击或触摸机身按键，方向键支持长按。右上角可开启原创芯片音效和音乐。

## 冒险目标

从苔野镇出发，在高草中寻找六种原创小精灵。战斗时削弱对手再投球，捕获三种不同的野生精灵后，沿中央小径向北、向东，挑战东北高台上的守林人，赢取徽章。

镇西诊所免费治疗伙伴，并补足八个精灵球与四瓶恢复药。战败会安全回到诊所。使用攻击、特技、药水及换队来制定策略。

进度自动保存在当前浏览器的 localStorage 中，也可以点击保存按钮或使用游戏内菜单保存。战斗中退出后会返回地图，并保留当时体力和道具。不提供云端同步。

## 验证

`npm run check` 检查脚本语法；`npm test` 运行十二项游戏逻辑与渲染测试，包括地图连通性、捕捉、资源、换队、战败、读档和最终徽章。

## 文件

- `dist/index.html`、`dist/style.css`：掌机外观、响应式页面、指南。
- `dist/app.js`：键盘、触摸、手记、音量、全屏、存档交互。
- `dist/game.js`：游戏状态、地图、战斗、菜单、存档和画面。
- `dist/sprites.js`：原创四色像素绘制。
- `dist/audio.js`：Web Audio 原创芯片音乐与音效，默认静音。

所有游戏像素图案均由代码绘制，无第三方图片素材。网页字体可在联网时加载 Google Fonts，断网使用系统后备字体。
